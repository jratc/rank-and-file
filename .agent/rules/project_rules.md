# Project Rules

1. **Tech Stack**: Use Next.js (App Router), TypeScript, Tailwind CSS, and Supabase (for database/auth).
2. **Music APIs**: Use generic interfaces for Music Providers so we can easily swap Spotify/Apple Music/YT Music logic.
3. **Verification**: Always generate a "Walkthrough" artifact after completing a feature to verify the UI works.
4. **Style**: Use "shadcn/ui" for components to ensure a clean, modern aesthetic.
